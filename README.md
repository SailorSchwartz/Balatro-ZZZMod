# Zenless Zone Zelatro

A Zenless Zone Zero themed mod for balatro. 

This is my first ever balatro mod and mainly done as an exercise.

Current jokers:
- Nicole (Last scored card in hand gives 1.4x mult)
- Billy (played aces take away chips and give mult instead)
- Anby (adds remaining hands and discards to mult)
- Nekomata (destroys final card of final hand and adds half its chips as money)
